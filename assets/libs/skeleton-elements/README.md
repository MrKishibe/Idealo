# Skeleton Elements

- Package: `skeleton-elements` 4.0.1
- License: MIT
- Source: https://www.npmjs.com/package/skeleton-elements

Include the stylesheet in a view:

```html
<link rel="stylesheet" href="assets/libs/skeleton-elements/skeleton-elements.css">
```

Example placeholder:

```html
<div class="skeleton-block skeleton-effect-wave" aria-hidden="true"></div>
```

The stylesheet also provides `skeleton-text`, `skeleton-image`, `skeleton-avatar`,
and the `skeleton-effect-fade`, `skeleton-effect-blink`, and
`skeleton-effect-pulse` effects.
